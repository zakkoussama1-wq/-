# integrations

Shopify installation preparation uses the official Shopify API SDK, non-embedded OAuth, encrypted offline sessions and uninstall webhook validation. See [the setup guide](../../../docs/SHOPIFY-INTEGRATION-SETUP.md) for prerequisites and live-test limitations. Product catalog synchronization, product webhook invalidation and read-only Shopify catalog UI are implemented with mocked HTTP coverage and local PostgreSQL validation. Live shop authorization is still unverified; Shopify order creation is not implemented. See ../../../docs/OWN-STORE-STAGES-1-2.md. Tracking remains opt-in test transport or local simulation; no production events are enabled by setup.
