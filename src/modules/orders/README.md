# الطلبات المحلية

الحفظ الفعلي في `orders.sqlite` عبر `createOrder`: تحقق خادمي، إعادة تسعير، مفتاح منع التكرار ومعاملة SQLite لسجل الطلب والحد الهاتفي. يحفظ الاسم والهاتف والعنوان والتسعير واسم المنتج والخيار والوقت والحالة. قراءة الطلبات وتحديث الحالة محميان بجلسة مالك على HTTP. كل استعلام تخزين مقيد بمعرف التاجر؛ لا يوجد SaaS متعدد الحسابات بعد.

الأسعار والكتالوج في قاعدتين منفصلتين؛ معاملة السجل لا تعني معاملة مخزون وتسعير موزعة. قبل الإطلاق يلزم ترحيل مخطط الأعمال إلى PostgreSQL وتحديد المخزون وسياسات الاحتفاظ والنسخ الاحتياطي. لا يُعتبر submitted عملية مدفوعة، ولا يوجد إرسال أحداث خارجية.
