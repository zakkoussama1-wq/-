# المرحلة الثالثة — الطلبات والمنتجات

أُعيد تصميم هاتين الصفحتين فقط. يحتفظ منشئ النموذج ونموذج العميل بوظائفهما الحالية، وتجديد تصميمهما ينتظر الموافقة التالية. لا يوجد نشر أو ربط Shopify.

- الطلبات: جدول بأسماء العملاء وأرقام الاتصال والمنتج والخيار والكمية وطريقة التوصيل والحالة والإجمالي والتاريخ والوقت بتوقيت UTC. بحث وتصفية الحالة والتاريخ، وترتيب التاريخ والإجمالي، وتقسيم الصفحات، وتصدير جميع الطلبات CSV كما في السابق.
- تفاصيل الطلب في نافذة مستقلة، مع تحديث الحالة عبر API الحالي. الحالات النهائية تبقى مقفلة، وتظل قواعد حجز المخزون وإعادته عند الإلغاء على الخادم دون تغيير.
- المنتجات: جدول بالاسم والحالة وعدد الخيارات والسعر الأدنى والمخزون المتتبع، وبحث بالاسم والخيار والمعرف وتصفية الحالة وترتيب الاسم والسعر وتقسيم الصفحات. عند وجود خيارات دون تتبع لا يُقدّم مجموع المخزون المتتبع باعتباره مخزونًا كاملًا.
- نافذة إضافة المنتج وتعديله تحتفظ بالاسم وصورة HTTPS والتفعيل والخيارات وأسعارها ومخزونها. المخزون الفارغ يعني دون تتبع؛ لا تُحذف الخيارات المحفوظة. تبقى مراجعة الحفظ على الخادم لحماية التعديلات المتزامنة، ويحصل النموذج على إشعار بعد الحفظ.
- مكوّن مشترك لتقسيم الصفحات، وألوان وأزرار وحالات تحميل وإشعارات من نظام التصميم القائم. العربية RTL والفرنسية والإنجليزية LTR، مع تمرير أفقي للجداول على الهاتف.

## التجربة على Windows

أوقف النسخة القديمة بـ Ctrl+C، ونزّل آخر نسخة من [GitHub](https://github.com/zakkoussama1-wq/-) عبر Code → Download ZIP، واستخرجها في مجلد جديد. انسخ `data\local-demo` من النسخة القديمة إلى مجلد `data` الجديد للاحتفاظ بالطلبات والأسعار والتصميم. لا تنقل `node_modules`، واحتفظ بالمجلد القديم.

شغّل **START-WINDOWS.cmd** مع Node.js 24 وانتظر **Ready**. اضغط **OPEN-DASHBOARD.cmd** ثم **المنتجات** لإضافة منتج وتعديل خياراته، أو **الطلبات** لمراجعة طلب وفتح تفاصيله وتحديث حالته. من **OPEN-FORM.cmd** أرسل طلبًا وهميًا، ثم ارجع للإدارة واضغط **تحديث الطلبات**. روابط localhost تعمل على حاسوبك بعد تشغيل الخادم؛ لا تتوفر معاينة خارجية في هذه الجلسة. [دليل Windows](../WINDOWS-START-HERE.md).

## الحفظ والتحقق

حُفظت نقطة رجوع قبل العمل: `checkpoint/pre-orders-products-redesign-20261101` عند `e878e65`. لم تتغير مخططات قواعد البيانات أو بيانات الجغرافيا أو الأسعار المحفوظة أو مسارات API. اختبارات الواجهة المحددة تستخدم استجابات اختبار للبحث والتصفح، واختبار رحلة الطلب يحفظ طلبًا فعليًا في قاعدة مؤقتة ثم يؤكده ويلغيه ويعيد تحميله للتأكد من الحالة النهائية. اختبارات إنشاء المنتج تتحقق كذلك من حفظ سعره ومخزونه وظهوره في النموذج. التحقق على Linux؛ لا يُدّعى اختبار Windows أصلي.

تعرض نافذة التفاصيل أيضًا الخصم والإجمالي النهائي المحفوظين، وأسماء الولاية والبلدية من المرجع حسب لغة الواجهة. عند تعذر قراءة الأسماء تبقى القيم الأصلية ظاهرة مع تنبيه، دون اختلاق عنوان أو تغيير الطلب.

نتائج الفحص: 38 اختبار تجربة محلية و34 اختبار ميزات سابقة ناجحة، و145 اختبار وحدة/تكامل ناجح. تُخطيت اختبارات PostgreSQL الأربعة لعدم تهيئة قاعدة اختبار لها؛ لم تتغير طبقة التخزين. نجحت فحوص البناء والأنواع وLint والتنسيق، وأُعيد فحص سيناريوهات المرحلة بعد مراجعة تفاصيل المنطقة والإجمالي.
