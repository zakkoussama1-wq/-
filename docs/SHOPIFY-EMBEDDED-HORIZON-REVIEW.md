هذه عيوب مثبتة في التغطية/التصميم، وليست إثباتًا بعد لسبب اختفاء البلوك في المتجر
الحقيقي. لا يوجد DOM حي/لقطة في أداة الصفحة (page_id=null)، ولا هوية متجر/توكن
متاحان. لا نستنتج مشكلة Cookies: API المتجر يعتمد توقيع App Proxy وليس جلسة التاجر.

## مصادر الفحص وحدوده

- مصدر Horizon الرسمي: https://github.com/Shopify/horizon عند
  99604908f1af345214ece67b9e2c5660886f37ea. يدعم _product-details بلوكات @app،
  ويستخدم closest.product. أحداث نسخته الحالية تعتمد ProductSelectEvent مع promise
  من @shopify/events؛ نسخ أقدم تستخدم variant:update.
- Shopify SDK المثبت يتحقق من JWT عبر session.decodeSessionToken باستخدام HS256
  والمفتاح السري وaudience والمهلة. سنضيف فحص dest/iss/claims وربط التثبيت الفعال.
- رابط WEBI الرسمي وshopify.dev محجوبان بسياسة شبكة هذه البيئة؛ لا ندعي فحص
  الصورة المفقودة أو معرفة البنية الداخلية لـWEBI. نطبق نمط التنقل والتركيب المطلوب
  دون نسخ شعار أو كود أو تصميم.
- لا يمكن تشغيل Theme Editor الحقيقي محليًا؛ اختبار DOM/CSS وأحداث Horizon المعزول
  يثبت التوافق مع الحالات المختبرة فقط. يلزم قبول يدوي في متجر المالك بعد نشر منفصل.

## حدود التنفيذ

لا نشر/Commit/push في هذه الجولة. لا تغيير إعدادات الخدمات الحقيقية أو الجداول أو
البيانات القديمة. DZ_SHOPIFY_ORDER_SYNC=0 يبقى كما هو؛ لا orderCreate أو Purchase أو
إشعارات أو تعديل مهام single_order. OAuth الحالي لا يستبدل ولا تُسجل التوكنات.
نقطة الدخول Embedded تتطلب تثبيتًا موثقًا موجودًا؛ تركيب متاجر جديدة وتوزيع التطبيق
وتفعيل embedded في Shopify خطوات لاحقة يراجعها المالك وليست تغييرات تلقائية.
